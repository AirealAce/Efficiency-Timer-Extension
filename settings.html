Reflection Timer

Extension settings

Responses go through your Google Apps Script web app. The extension never stores a Google service-account private key.

Connection

The configured Apps Script will only accept this spreadsheet ID.

Uses your computer's local date. Accepts MM/DD/YYYY or MM/DD/YY, with or without leading zeros. If both exist, the four-digit year wins. A missing daily tab is copied from your template when you first send, using MM/DD/YYYY.

New entries go at the top of A:B, with alternating timestamp colors and a full-width themed divider for each new hour. New rows shift all columns down together. Test reflection prompts always save to the test tab, never Temp or Template.

Use the deployed /exec URL, not the editor or /dev URL.

Use the same value for the Apps Script property REFLECTION_API_TOKEN.

Debugging & activity log

On by default. Records timer actions, tab IDs and visibility, worker starts, alarm timing, prompt delivery, and error categories. No browsing URLs, page titles or contents, reflection text, tokens, or connection settings. Nothing is sent to a server.

Keeps up to 1,200 events from the last 7 days, whichever is less. Pausing stops new records; clearing removes the saved log. Activity timestamps can still be personal—review reports before sharing.

One-time Apps Script setup

      
    
        
  1. Open the Sheet and select Extensions → Apps Script.
    2. 
        
  2. Replace the editor contents with google-sheets-script.gs from this extension folder.
    3. 
        
  3. In Apps Script Project Settings → Script properties, add SPREADSHEET_ID and REFLECTION_API_TOKEN.
    4. 
        
  4. Deploy as a web app that executes as you and allows anyone to access it. The token protects writes.
    5. 
        
  5. Paste the resulting /exec URL above, save, and test.
    6. 
      

      
After changing the Apps Script code, create a new deployment version for the changes to take effect.
