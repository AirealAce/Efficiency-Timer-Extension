Your timer. Your spreadsheet.

Reflection Timer is a Windows desktop focus timer. It runs in the system tray, asks for reflections, and sends entries directly to a Google Apps Script receiver in your Google account. The app author does not receive your reflections or credentials.

Install · New spreadsheet · Another PC · Credentials · Troubleshooting · Privacy

1. Download and open

  1. Obtain the Windows x64 ZIP from the publisher's verified release. Use the packaged app, not GitHub's “Source code” ZIP. This package targets Windows 11 on Intel/AMD 64-bit PCs; other operating systems/architectures are not verified.
  2. Right-click the ZIP → Extract All. Open the extracted folder, then double-click ReflectionTimer.exe. Do not launch from inside the ZIP. The public package includes .NET; there is no separate runtime, Node, Python, Chrome extension, or administrator setup to install.
  3. Guided setup opens on a fresh PC. Optionally choose Install on this PC on step 1 to copy the app into your per-user Programs folder and create Desktop/Start menu shortcuts. After installation, close the portable copy with Quit desktop app and open the installed shortcut. No admin access or Windows security changes are needed.
  4. Upgrading? First choose Quit from the old app's tray menu (X only hides it). Extract and launch the new package, then Install on this PC. Existing settings, local drafts, and bundled personal MP3s are preserved; the old installed folder is kept as a backup.

Unsigned download: Windows may show a publisher/reputation warning. Verify the source, checksum, and code before deciding whether you trust it. Do not disable Defender, change security policy, or bypass organizational restrictions. A release checksum detects corruption, not a malicious publisher. The app is not represented as Microsoft- or Google-verified.

2. Connect a NEW spreadsheet

Allow about 5–10 minutes for the one-time Google setup. Future PCs can use a single private setup code. Google authorization and deployment must be completed by you; the app cannot silently approve access for you.

  1. Open Google Sheets while signed into the account that should own your data. Create a blank spreadsheet, or choose one you own and can edit. A dedicated spreadsheet is simplest. Do not use the developer's spreadsheet. Leave sharing private unless you intentionally want collaborators.
  2. Open Reflection Timer → Settings → Guided setup / another PC. On step 1 leave “Use an existing receiver” unchecked. Paste the spreadsheet's browser URL, then click Generate private token. It creates a fresh, random 256-bit secret on your PC and saves the setup draft encrypted. This is NOT your Google password or a Google API key.
  3. On step 2 click Copy setup script. In your chosen spreadsheet, use Extensions → Apps Script. In the new, dedicated project, replace the starter Code.gs with the copied script and save. Do not replace unrelated automation. The personalized script includes your secret: do not publish it or paste it into support tickets.
  4. Select setupReflectionTimer in the function dropdown at the top, then click Run. Review the requested Google access and authorize with the account that owns the spreadsheet. The script must be opened from this same spreadsheet. It automatically configures the spreadsheet ID and token, and creates missing Temp and test tabs. Existing tabs and content are not cleared. You may keep the original blank Sheet1 tab.
  5. If Google shows “Google hasn't verified this app,” verify that the named developer is your own account, this is the project you just created, and you trust the code. Google may describe broad spreadsheet permissions because Apps Script uses the Sheets service; the receiver's own validation limits requests to the configured spreadsheet. If these details do not match, or you are unsure, stop. Google describes the warning in its verification guide. Only after you independently accept those risks should you use Google's offered advanced continuation and authorization controls. Never provide your Google password, verification code, or recovery codes to Reflection Timer or another person.
  6. After the setup function finishes, choose Deploy → New deployment. Select the gear/type → Web app. Set Execute as: Me (your account) and Who has access: Anyone, then Deploy. Complete Google's authorization if requested. This is access to the endpoint, not public sharing of your Sheet: writes still require the private token and the exact configured spreadsheet. “Anyone with a Google account” and “Only myself” require browser login and do not work with this desktop client. Your Workspace organization may prohibit anonymous web apps; ask its administrator or use a permitted account. Do not bypass its policy.
  7. Copy the Web app URL, which looks like https://script.google.com/macros/s/…/exec. In Guided setup step 3, paste it. An editor URL containing /home/projects/…/edit or a test URL ending /dev is not the deployment URL.
  8. Keep automatic dated tabs selected unless you specifically want one fixed tab. Check that the Chrome timer extension is off or was never installed. Click Check connection. It checks your normal destination and test without inserting anything. Confirm the displayed spreadsheet is yours, then click Save and finish.

Finished! The next real entry uses the local date when you send it. If that day's tab is missing, it is copied from your template. Existing names such as 09/09/2026 and 9/9/26 are supported. Test reflection prompt submissions go only to test. Do not use test prompts for real records.

Need to pause setup? Close setup normally to save its edited fields and existing-receiver choice as an encrypted draft, without activating that connection. If the draft cannot be saved, the app asks whether you want to keep it open or discard the edits. Generating a replacement token requires confirmation when a draft token already exists; a replacement will not automatically update the token in an already deployed script.

3. Use the same spreadsheet on another PC

  1. On your already configured PC, open Guided setup → step 3 → Copy private setup code. This copies the saved connection, not unfinished edits in the wizard. Complete and save setup first if this PC is not yet configured. Keep the code in your password manager or transfer privately to your trusted PC. It includes the secret token in a readable encoded format; it is not encrypted. Clipboard history/sync may retain copied secrets.
  2. On the other PC, install/open the app. On Guided setup step 1, paste the code into “Private setup code from another PC,” then click Use private setup code.
  3. Confirm the destination, click Check connection, then Save and finish. No new Google authorization, template, token, or deployment is needed if the existing connection is still valid.

You can also select “Use an existing receiver” and enter the three fields manually. A different person should normally create their OWN connection, rather than receiving yours. Sharing your code intentionally grants the ability to submit entries to your receiver.

Each PC retains independent timers, schedules, settings, drafts and local history. The Sheet receives entries from each PC, but this is not a cross-device timer synchronization feature. Avoid running duplicate sessions if you do not want both logged. Custom MP3 files must also be present on the new PC; choose them again in Audio settings.

Where each credential comes from

FieldWhere to find it
Google Sheets URLYour spreadsheet's browser address bar. The ID is the part between /d/ and the next slash.
Apps Script deployment URLYour Apps Script project → Deploy → Manage deployments → select the Web app → copy its URL ending in /exec. Do not use the editor address.
Reflection API tokenGenerated by Guided setup for a new connection. For an existing connection: your other PC's saved connection, or Apps Script → Project Settings → Script properties → REFLECTION_API_TOKEN.

There is no service-account JSON, client secret, OAuth access token, or billing setup to obtain. Don't generate a new Reflection token when adding a PC: it must match your receiver's Script Property.

Updating or repairing the receiver

A newer desktop version may need a receiver update to enable new features. Keep the same Script Properties, especially REFLECTION_API_TOKEN, SPREADSHEET_ID, TEMPLATE_SHEET_NAME, and RT_RECEIPT_*. Copy the generic google-sheets-script.gs supplied in the download into the existing receiver project, save, then Deploy → Manage deployments → edit (pencil) → Version: New version → Deploy. Do not run a newly generated setup wrapper over an existing connection. Saving source alone does not update the deployed web app. The deployment URL normally stays the same. Check the connection afterward.

To change the template name, edit TEMPLATE_SHEET_NAME in Script properties to match an existing tab exactly. Setup prefers an existing Temp or Template and otherwise creates Temp. Real entries preserve full-row hour themes and borders; columns C/D remain numeric durations.

Troubleshooting

Switching accounts or spreadsheets: finish your current session and pending reflections first, and deliver queued entries to their original destination before changing accounts. Correcting the token, changing the browser URL suffix for the same Sheet, or adding/removing the deployment URL's trailing slash is allowed. Incomplete first-time setup can be finished while a timer or draft is open, provided it does not change an already usable destination. Missing/invalid destination fields in never-attempted pending entries can be completed; their original text and save times are retained. Previously attempted entries are not reassigned. Saving a different connection manually clears an older setup draft, so the next Guided setup does not suggest stale credentials.

Installation recovery: if file replacement fails, the installer attempts to restore the previous app folder. If restoration is also blocked, it displays the retained backup location; keep that folder and your local data for recovery. A shortcut conflict does not undo a successful installation: use the displayed installed executable path, or a shortcut that was successfully created. Existing conflicting shortcuts are not overwritten.

Unconfirmed delivery: a generic health response is not proof that an entry was saved. Incomplete acknowledgements and oversized responses leave the entry available for review in the Outbox. Check the Sheet before explicitly retrying. Each network request has a 25-second overall deadline, including redirects and body reads; supported, retry-protected entries can retry transient interruptions with their original ID.

Installation reports a redirected path: extract the ZIP into a regular local folder (such as Downloads), not a linked/junction folder. Do not change Windows security settings. A malformed or damaged package is rejected before replacing the existing installation; download and extract a fresh copy.

  • No /exec URL yet: create the Web app deployment; the editor URL is not enough.
  • Google login page / invalid JSON / unexpected redirect: verify Execute as Me, access Anyone, and that the deployment is active. Recheck your organization's restrictions. A public browser health page saying “success” does not verify the private token or destination.
  • Request rejected: verify that the token matches REFLECTION_API_TOKEN and the Sheet ID matches SPREADSHEET_ID. Confirm your Google account can still edit that Sheet. Don't copy the quotes around a token.
  • Template missing: restore the configured template tab or correct TEMPLATE_SHEET_NAME. A connection check never creates missing daily tabs.
  • Test tab missing: add a tab named exactly test. The test button will never silently fall back to a live dated tab.
  • Receiver needs update: follow the update section above to retain check-ins and protected retries.
  • App doesn't alert while closed/asleep: X keeps it running in the tray; Quit stops it. It does not wake a sleeping PC. Optional Windows sign-in startup is in Settings.
  • Shortcut conflict: Settings lists all five shortcuts and any conflict. Quit the other app using that shortcut and restart Reflection Timer. The tray menu's Check in to current session is also available if comma is reserved.
  • Only Ctrl+Alt+T works on another PC: version 3.6.4 did not include the punctuation shortcuts. Upgrade the executable, not the Sheet connection. See current shortcuts and safe upgrade checks. Close the old copy using Quit before installing; preserve your existing credentials.
  • Audio file missing: select a readable MP3 in Audio settings. Public downloads use built-in tones; personal game soundtracks are not redistributed. All volume, preview, fade, assertive/polite/disruptive, and None options remain available.
  • Need help: use Mark issue and export diagnostics. Review before sharing; never include your private setup code, credentials, personalized script, or state files. There is no automatic diagnostic upload.

Your records and controls

Sheet columns: A timestamp, B reflection, C actual active time, D allotted time, E “ended early,” “Check-in,” or blank on completion, F optional early-end reason. Check-ins are cumulative snapshots, so exclude them when summing completed sessions to avoid double counting. Pauses do not count toward active time.

Existing timer features are retained: schedules with independent options and overlap rules, automatic restart and cutoff, low-time warnings, four themes, compact/tray view with saved placement, offline queue and protected retries, optional start at sign-in, editable sounds and app/event volume.

  • Ctrl+Alt+T: focus main app.
  • Ctrl+Alt+`: start/resume, or end a running session early.
  • Ctrl+Alt+/: compact controls → time-only → hidden.
  • Ctrl+Alt+.: focus compact duration; press twice within 0.8 seconds for the full timer.
  • Ctrl+Alt+,: current-session check-in. Pending reflections opens older drafts.
  • Enter in duration: start/resume. Ctrl+Enter in settings/reflection: save.

Data ownership and privacy

Your Google account owns the spreadsheet and receiver. The developer is not added as a collaborator. Requests go from your PC to your configured Google Apps Script endpoint; Google stores/processes that data under its own terms. Script editors can read its token, so restrict access to the spreadsheet and script to trusted collaborators. Keep the original Sheet sharing private unless you deliberately choose otherwise.

Timers, settings, credentials, drafts and outbox are stored in %LOCALAPPDATA%\ReflectionTimerDesktop, encrypted using Windows DPAPI for your Windows account. This protects files at rest, not against software already running as you. state.dat and backups cannot simply be copied to a different PC/profile and decrypted. Use a private setup code for the connection; historical submitted records already live in your Sheet. The app does not read your browser profile, track web browsing, send analytics, or synchronize local timers between PCs.

Uninstalling application binaries need not delete your data. Keep encrypted local backups with the Windows profile/keys needed to recover them. Revoke a connection by disabling its Apps Script deployment or replacing REFLECTION_API_TOKEN with a new private token and updating each trusted PC. Revocation stops future submissions; it does not delete existing Sheet rows.
