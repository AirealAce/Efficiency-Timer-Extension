# Local soundtrack library

The user supplied local MP3 copies from Pokémon Diamond, Pearl, & Platinum Restored Soundtrack (2006) and Kirby & The Amazing Mirror (GBA) (gamerip) (2004). Original files are unchanged. These assets are excluded from Git/public distribution; the local build includes any copies present here next to the installed executable.

| Local filename | Original track |
| --- | --- |
| pokemon-obtained-item.mp3 | 1-12. Obtained an Item! |
| pokemon-level-up.mp3 | 1-36. Level Up! |
| pokemon-healed.mp3 | 1-17. Pokémon Healed |
| pokemon-key-item.mp3 | 1-23. Obtained a Key Item! |
| pokemon-battle-trainer.mp3 | 1-20. Battle! (Trainer) |
| pokemon-battle-champion.mp3 | 2-67. Battle! (Champion) |
| kirby-out-of-health.mp3 | 28 Out of Heath (source filename spelling) |

The tracks retain their original lengths; the battle tracks are music, not shortened effects. Playback is once through, never looped. A build without these local assets falls back to the original extension sound. No assets are fetched automatically. Public source/builds must not be assumed to include redistribution rights to these soundtracks.
